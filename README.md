# TinyCrop Downloads

這是 TinyCrop for macOS 的公開下載頁面。原始碼存放在私人專案，此處只提供安裝檔。

## 下載與安裝

1. 前往 [最新版本](https://github.com/james1239090/TinyCrop-Downloads/releases/latest)。
2. 在 **Assets** 下載名稱以 `.dmg` 結尾的檔案。
3. 開啟 DMG，將 **TinyCrop.app** 拖到 **Applications**。
4. 更新前請先儲存照片並結束舊版 TinyCrop，再用新版取代舊版。

下載不需要 GitHub 帳號。TinyCrop 支援 Intel macOS 10.13.6 以上，以及 Apple Silicon macOS 11 以上。

目前安裝檔使用臨時簽署，第一次開啟時可在 Finder 對 TinyCrop 按右鍵，選擇「打開」。
